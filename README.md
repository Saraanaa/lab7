# Lab 07 — Session-Based Test Management

Оюутан: Г. Саранчимэг B232274001

Код: `node app.js`

Node хувилбар: `v22.19.0`

Апп: `http://localhost:3000`

Энэ repository нь өгсөн `app.js` дээр хийсэн exploratory testing-ийн charter, session report, нотолгоо болон bug report-уудыг агуулна. Аппын эх кодыг өөрчлөөгүй.

## Файлын бүтэц

- [charter.md](./charter.md) — session эхлэхээс өмнө бичсэн charter
- [session-report.md](./session-report.md) — туршилтын явц, саад, цагийн зарцуулалт
- [bugs/](./bugs/) — тус бүрдээ нэг үндэслэлтэй согогийн тайлан
- [evidence/](./evidence/) — API туршилтын бүтэн гаралт
- [screenshots/](./screenshots/) — UI нотолгооны зураг

## Дүгнэлт

Saboteur аялал хамгийн өндөр үр дүнтэй байсан: буруу JSON хүсэлт 200 OK авч байгаа нь API-ийн тодорхой зөрчил болохыг curl-ийн бүтэн гаралт баталсан. Supermodel аяллаар `/old` холбоосын 500 алдаа болон устгасны дараах буруу мессеж ажиглагдсан. Fed-Ex аяллаар статистикийн тоо бодит жагсаалттай нийцэхгүй, мөн давхардсан ном нэмэгдэх боломжтойг илрүүлсэн. Charter-аас гадуур он талбарын баталгаажуулалт болон case-sensitive хайлт ажиглагдсан. Зарим согогийг Playwright зэрэг автомат тестээр барьж болох ч UI мессежийн утга, харагдах өнгө, холбоосын алдаа нь хүний нүдээр шалгахад илүү тодорхой байв. Дараагийн session-д засварын дараах regression болон өгөгдлийн хадгалалтыг тусад нь шалгана.
