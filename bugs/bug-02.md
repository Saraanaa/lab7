# BUG-02: Хуучин хувилбарын холбоос 500 алдаа буцаана

Орчин: Уншлагын жагсаалт v2.0, Chromium/Node.js, 2026-11-19

## Дахин гаргах алхам

1. Нүүр хуудасны доод хэсгийн `Хуучин хувилбар` холбоосыг дарна.

Хүлээгдэж байсан: холбоос ажиллаж, хуучин хувилбар эсвэл ойлгомжтой redirect харуулах.

Бодит үр дүн: HTTP 500 `Internal Server Error`.

Ноцтой байдал: Major — харагдаж буй үндсэн холбоос эвдэрсэн.

Олсон аялал: Supermodel.
